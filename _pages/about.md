## Selected work

### Photoionisation-model inference
Cloudy + MaNGA pipeline using 3D line-ratio spaces, KDE, RBF interpolation, and Bayesian inference.

### Fast O(N log N) 3PCF algorithm
C++ and OpenMP implementation of pair-counting as in-situ convolution for large-scale-structure statistics.

### Interpretable radio-galaxy classification
CNN + LIME workflow for auditing model attention and failure modes in FR-DEEP/FIRST images.
